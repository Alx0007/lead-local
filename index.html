Como gerar a chave do Places sem risco de ser cobrado
  1. Entre em console.cloud.google.com e crie um projeto novo.
  2. Ative a Places API (New) na biblioteca de APIs.
  3. Em "Credenciais", gere uma chave de API e cole aqui.
  4. O passo que protege seu bolso: em "APIs e serviços → Places API → Cotas", defina um limite diário baixo (ex.: 200 requisições/dia). Estourou a cota, a API simplesmente para de responder — não gera cobrança.
  5. Crie também um alerta de orçamento em "Faturamento → Orçamentos" com valor R$ 1, só pra ser avisado se algo escapar.

Como pegar a chave grátis do Gemini (2 minutos, sem cartão)
  1. Entre em aistudio.google.com com a mesma conta Google.
  2. Clique em "Get API key" e depois em "Create API key".
  3. Copie e cole no campo acima. Pronto — não pede cartão.
  4. O nível gratuito dá algo em torno de 1.500 chamadas por dia no modelo Flash, o que é muito mais do que você vai usar escrevendo mensagens uma a uma.

Envio automático pelo WhatsApp uazapi

Com isso o app dispara a mensagem sozinho, sem abrir o WhatsApp Web.

Leia antes de usar. A uazapi é um gateway não-oficial: ela conecta no seu WhatsApp como se fosse o WhatsApp Web. Isso está fora dos termos de uso do WhatsApp, e o número que corre risco de banimento é o seu. Use um chip separado do pessoal, respeite o intervalo e o teto diário abaixo, e não mande o mesmo texto para todo mundo — mensagem repetida em massa é o padrão que o WhatsApp detecta.
Fica só no seu navegador, como as outras chaves. Não vai para dentro do código.
Mínimo 20. O app sorteia uma variação em cima disso, para não sair num ritmo de robô.
Comece baixo. Chip novo disparando muito é o que derruba.
